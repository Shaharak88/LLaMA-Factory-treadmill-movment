Testing video playback with local HTTP server

⚠️ IMPORTANT: How to View This Page

Videos ONLY work when served via HTTP server! They won't play if you just double-click the HTML file.

To view this page properly:

  1. Open a terminal/command prompt in this directory
  2. Run: python -m http.server 8000 (or python3 -m http.server 8000)
  3. Open your browser and go to: http://localhost:8000/test_videos.html
  4. Videos should now play! ✅

Alternative (Windows):

Double-click START_SERVER.bat then open http://localhost:8000/test_videos.html
